## Crash recovery

The first agent process was force-stopped while `STAGE_VERIFY` was leased on attempt 1. The lease
expired naturally after 60 seconds. A new agent process reclaimed the same job on attempt 2,
discarded the partial staged directory, rebuilt it, and continued without duplicating a final
destination.

The live run also exposed a robocopy compatibility issue before completion:
`\\?\UNC\...` arguments returned exit code 16 on this Windows installation. Read-only diagnostics
showed the extended form failing with errors 123/53 while normal UNC returned success code 1.
ADR 0006 records the narrow process-boundary conversion. After the correction, production copy and
verification both succeeded on attempt 1.
